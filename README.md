# Ткани оптом · Ала-Тоо A1/2-22 С

Каталог тканей магазина на рынке Ала-Тоо (бывш. Мадина), блок А, A1/2-22 С, Бишкек. Заказ — через WhatsApp.

- Товары: `products.js` (название, код, фото), контакты — `SHOP` там же
- Фото: папка `img/` (`img/og.jpg` — превью для соцсетей, 1200×630)
- SEO: `robots.txt`, `sitemap.xml`, JSON-LD и HTML-версия каталога в `index.html` (блоки `<!--pre:…-->`)
- После любого изменения `products.js`: из корня проекта `node scripts/site_prerender.js` — обновляет блоки в `index.html` и `sitemap.xml`
